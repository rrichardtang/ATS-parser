# Agent Notes

Role-scoped running logs for `bob-the-builder` and `felix-the-fixer`, local to this repo —
not the project's `PROJECT_NOTES/`. Each file is a short factual log of things future rounds
of that specific role should know here (recurring bug classes, root causes, reviewer/build
preferences specific to this repo), appended one terse line at a time by the agent itself.

- `bob.md` — bob-the-builder's log. Created on its first noteworthy entry.
- `felix.md` — felix-the-fixer's log. Created on its first noteworthy entry.

See `rrichardtang/claude-config`'s `CLAUDE.md` for the full loop protocol these support.
